# HEARTBEAT.md

## Always Active
- USB-first
- no fixed drive-letter assumptions
- verify before claiming success
- ask only when truly necessary
- preserve working systems
- no fake completion

## Session Start
1. Assume USB setup is the source of truth.
2. Load only the minimum continuity needed.
3. Retrieve only task-relevant memory.

## Before Action
Check current evidence and choose the best single workable path.

## Before Reporting
Do not report success until the key requirement is checked.

## Continuity Rule
Prefer the small bootstrap first; read deeper continuity only when needed.

## Lesson Rule
After significant failure or repeated friction, store the lesson.
